# Web Fauzia Family

## 1. Nama Tema
Web Fauzia Family

## 2. Deskripsi
Web Fauzia Family adalah tema WordPress untuk blog pribadi
yang digunakan sebagai media berbagi cerita, pengalaman,
pengetahuan, dan inspirasi.

Tema ini memiliki desain modern dengan perpaduan warna hijau
dan putih agar tampilan website terlihat menarik, nyaman,
dan mudah digunakan.

## 3. Fitur Tema
- Header dengan logo dan nama blog.
- Menu navigasi website.
- Sidebar interaktif yang dapat dibuka dan ditutup.
- Halaman beranda.
- Halaman daftar artikel atau blog.
- Halaman detail artikel.
- Footer yang berisi informasi blog dan navigasi.
- Desain responsif untuk berbagai ukuran layar.
- Informasi hak cipta pada bagian footer.

## 4. Teknologi yang Digunakan
- WordPress sebagai platform website.
- PHP untuk membuat template dan menghubungkan fitur WordPress.
- HTML untuk menyusun struktur halaman.
- CSS untuk mengatur desain dan tampilan website.
- JavaScript untuk mendukung interaksi sidebar.

## 5. Struktur File
- style.css: Identitas tema dan pengaturan tampilan.
- index.php: Template utama tema.
- functions.php: Pengaturan dan fitur tema.
- header.php: Bagian header dan navigasi.
- footer.php: Bagian footer website.
- front-page.php: Template halaman beranda.
- single.php: Template detail artikel.
- archive.php: Template daftar artikel.
- README.md: Dokumentasi tema.
- screenshots/: Folder dokumentasi screenshot website.

## 6. Petunjuk Instalasi
1. Pastikan WordPress sudah terpasang.
2. Salin folder tema ke direktori wp-content/themes/.
3. Masuk ke dashboard WordPress.
4. Pilih menu Tampilan > Tema.
5. Cari tema Web Fauzia Family.
6. Klik Aktifkan.
7. Buka halaman website untuk melihat hasil tema.
